# Çamaşır Sarayı · Hafta 2 · Aşama 1

Üniversite final projesi için bağımsız Kotlin + XML iskeleti. Bu aşamada karşılama ekranı çalışır ve iki kart ilgili aşamanın bilgisini gösterir. Paket kimliği com.camasirsarayi.hafta2.

Android Studio ile bu klasörü açıp Gradle eşitlemesinden sonra Run kullan. Android SDK 36 ve JDK 17 veya uyumlu Android Studio JDK'sı gerekir. Windows terminalinde gradlew.bat :app:assembleDebug komutuyla debug APK üretilebilir.

GitHub'da boş bir depo oluşturduktan sonra git remote add origin DEPO_URL ve git push -u origin main komutlarını kullan.
